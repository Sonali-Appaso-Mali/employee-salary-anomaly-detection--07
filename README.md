# Employee Salary Anomaly Detection
Employee Salary Anomaly Detection using data mining techniques. This project standardizes salary data with feature scaling and identifies outliers across departments using statistical analysis. Built with Python, Pandas, NumPy, and Scikit-learn to uncover inconsistencies in salary structures and improve data-driven decision-making.



## Overview
This case study analyzes employee salary data to detect anomalies across departments. The data is standardized using feature scaling techniques to improve accuracy in identifying outliers.

## Objective
- Standardize salary data  
- Analyze salary distribution  
- Detect outliers using statistical methods  

## Methodology
Data Cleaning → Data Preprocessing → Feature Scaling (StandardScaler) → Outlier Detection  

## Tools and Technologies
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Google Colab  

## Requirements
pandas, numpy, scikit-learn, matplotlib, seaborn  

## Execution
Open the notebook in Google Colab, upload the dataset if required, and run all cells sequentially.  

## Visualization
A box plot is used to represent salary distribution and identify potential outliers.  

## Results
Most salary values fall within a consistent range, with no significant outliers observed. This indicates a relatively stable salary structure.  

## Conclusion
The analysis shows that the dataset is fairly uniform with minimal anomalies. Feature scaling improved the effectiveness of detecting inconsistencies.
